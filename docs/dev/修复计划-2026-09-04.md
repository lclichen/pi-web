# 安全修复与多机连接计划（2026-09-04）

> 依据：同日两项目代码评审（pi-web + AgentSandbox/sandbox-platform）。
> 本文档是唯一任务清单；完成项打勾并注明 commit。测试方案见
> `docs/dev/全流程测试方案.md`（本次已增补 §8 安全回归、§9 多机连接用例）。

## 目标

1. 消灭评审发现的全部 P0（越权/默认不设防），收敛 P1。
2. 新增能力：**同一用户可配对多台本机 agent，按项目选择机器**。
3. 不破坏既有 L1 用例；每阶段通过 L0（tsc + npm test / vitest）后再 commit。

## 阶段与任务

### Phase B — pi-web 安全修复（P0/P1）

- [B1] `proxy.ts`（Next16 middleware）改为**真实会话校验**（导入 lib/web-session，
      Node runtime），匿名/伪造 cookie 一律 401/跳登录；保留公开白名单：
      `/api/webauth/*`、`/api/agent-relay/download/*`、静态资源。
- [B2] `lib/file-access.ts` fail-open 修复：`!identity.ok` 返回**空集合**而非 host 全量根。
- [B3] `app/api/agent-relay/rpc/stream/route.ts`：鉴权失败直接 401，不再 `userId:0` 软失败。
- [B4] `lib/relay/relay-store.ts`：`token in file.tokens` → `Object.hasOwn`（原型链绕过）；
      token 记录带 machineId/label/lastSeenAt/issuedAt（多机数据结构迁移，向后兼容旧数字格式）。
- [B5] `app/api/remoteterminal/[sid]/{input,resize,close,events}` 四路由补属主校验
      （对照 terminal registry 中 ctx.userId / admin 放行）。
- [B6] 旧栈 `app/api/agent-relay/terminal/*`：create/input/close/events/resize 全部
      补 requireUserIdentity + 属主（events 订阅校验归属 agent 的 owner）。
- [B7] 配对接口加固：`/pair/exchange` 失败计数限速（每 IP 10 次/分钟 + 全局
      60 次/5 分钟），CORS 收紧（去掉 `*`）；配对码单次消费已有，补 code 熵
      （拒绝采样消除 modulo bias）。
- [B8] 登录接口限速：`/api/webauth/login` 每 IP+用户名 10 次/分钟（内存计数）。
- [B9] `lib/web-session.ts`：持久化改用 atomic-file（tmp+rename）；sweeper 过期时
      同时吊销平台 API key（消除孤儿 key）；cookie Max-Age 与服务端 TTL 对齐。
- [B10] exec 超时单位统一（见 E4，TS 侧文档改 ms 并 clamp）。

### Phase C — sandbox-platform 安全/健壮性修复

- [C1] fail-closed 启动：JWT_SECRET 未设→自动生成临时随机值+告警；显式设为已知
      弱值→任何环境拒绝启动。种子 admin 用默认弱口令→强制 `must_change_password=1`。
- [C2] `EXECUTOR_KIND` 默认 `mock`→`auto`（SSH_HOST 配了→ssh；本机有
      apptainer→cli；否则报错要求显式 mock）；production 显式 mock 也拒绝；
      mock 执行器环境变量改**白名单**（PATH/TEMP/HOME/LANG/TZ/SYSTEMROOT 等），
      杜绝 JWT_SECRET/SSH_PASSWORD 泄入"容器"。
- [C3] PTY 鉴权改造：新增一次性短时 ticket（POST /containers/:id/pty/ticket，
      60s 单次），WS 只认 `?ticket=`；移除 `?token=` 长期凭证直连。WS 加
      `maxPayload=1MB`，input 限速（每会话 256KB/s + 总量上限）。
- [C4] tools 资源边界：bash stderr 截断（与 stdout 同策略）；read 尺寸上限（2MB）；
      grep 行长上限（10KB 截断后再匹配）+ pattern 长度上限 + walkFiles 文件数预算。
- [C5] 管理员重置密码→吊销全部 refresh token + bump token_version；access token
      增加 `tv` claim，middleware 校验用户行 token_version（吊销即时生效）。
- [C6] 容器生命周期：每容器互斥锁（start/stop/snapshot/restore/destroy/reaper）；
      reaper stop 前重读行状态并在锁内执行；snapshot finally 重启前复查行状态；
      ssh stop/destroy 校验退出码，destroy 对活实例拒删 overlay。
- [C7] 快照恢复原子化：拷到临时目录后原子换名，失败保留原 overlay。
- [C8] backup 保留策略（默认保留最近 20 份）；`migrate:rollback` 加破坏性确认
      （需 `--force` 且有数据时二次提示退出码）。
- [C9] JWT verify 固定 HS256；login 用户不存在时跑 dummy bcrypt（时序）；change-password
      限速；admin PATCH 自我保护（最后一个 admin 不可自降/自禁/自删）。
- [C10] 文档漂移修正（503→501、migrate seed 说明、vitest 注释）；/metrics 默认
      要求 token（`METRICS_PUBLIC=on` 才放开）。

### Phase D — 多机连接（新功能）

设计要点：
- **机器身份**：Go agent 首次运行生成持久 `machineId`（UUID 存 agent config），
  `/pair/exchange` 请求体带上 machineId+hostname，hello 帧也带（校验一致）。
- **token 存储**：`relay.json` tokens 值由 number 迁移为
  `{userId, machineId, label?, issuedAt, lastSeenAt}`；旧格式读时归一化。
- **registry**：`agentsByUser: Map<userId, Map<machineId, AgentConn>>`；同机重连
  逐出旧连接（不再逐出该用户全部机器）；`reg.agent` 保留为 auth-off 兼容。
- **路由**：`relayRpc/relayStream` opts 增加 `machineId?`；pty 订阅 key 改
  `machineId:sid`；RemoteSessionContext 增加 machineId。
- **项目绑定**：ProjectRecord 增加 `machineId?`；local-machine 会话解析时
  项目绑定优先，缺省回落用户"最近连接的机器"。
- **API**：`GET /api/agent-relay/machines`（列表：在线状态+元数据）、
  `POST /api/agent-relay/machines/[machineId]/rename`、`.../unpair`（吊销 token）；
  状态 SSE 带 machines 数组。
- **前端**：LocalMachinePanel 机器管理（列表/改名/解绑/新建配对）；
  新建 local-machine 项目与项目设置中机器选择器；多机时 SessionToolbar 显示
  当前机器。

- [D1] TS 侧数据结构与 registry/forward 改造 + 单测。
- [D2] API 路由（machines/rename/unpair、pair 带 label、status 带 machines）。
- [D3] remote-session/remote-terminal/relay-client/旧终端栈 穿透 machineId。
- [D4] Go agent：machineId 持久化 + exchange/hello 携带 + label 参数。
- [D5] 前端 UI（LocalMachinePanel 机器管理 + 项目机器选择器）。
- [D6] token 有效期（默认 90 天滚动，连接时刷新 lastSeenAt/过期）+ unpair 吊销。

### Phase E — Go agent 质量修复

- [E1] workspace symlink 逃逸：解析最长存在祖先目录后再拼接剩余段校验 containment。
- [E2] PTY UTF-8 跨块缓冲（聚合不完整多字节序列）；pty.exit 事件上报 +
      registry 分发 + remote-terminal 映射为 exit 帧。
- [E3] PTY 进程组清理（Setpgid + kill(-pgid)）；relay 侧断线不再 CloseAll（保留
      会话，重连后按 sid 续接或至少可关闭）——若实现成本过高，降级为保留 PTY
      N 分钟等待重连。
- [E4] exec 超时单位统一为 ms（协议文档同改）；connectLoop backoff 成功后复位。
- [E5] 本地安装 Go 工具链（经 7890 代理）做 `go vet`/`go build` 验证。
