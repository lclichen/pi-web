## 三、决策记录（用户 2026-10-08）

1. **pi 包直升 1.1.0**：上游 0.10.0 用 1.0.0；1.0.0→1.1.0 对 pi-web 无破坏性变化（coding-agent 1.1.0 无 breaking；pi-ai 1.1.0 唯一 breaking=stream 函数须返回 AssistantMessageEventStream，我方已用 createAssistantMessageEventStream；tui 1.1.0 Terminal.setProgramStatus 需在 bump 阶段核 Terminal 实现者）。merge 后统一 bump，不落 1.0.0 中间态。
2. **执行顺序 = 先 merge 上游、后 bump pi**：上游已在其代码里完成 0.85.1→1.0.0 适配（rpc-manager 34 提交/+723 行）；先 bump 会与上游适配撞行、冲突翻倍。
3. **MCP**：保留 pi-mcp-adapter（现役 2.34.0，pi-web 类型镜像尚停 2.15.0 待同步）；配置 `extensions: ["-builtin:mcp"]` 显式关内置；内置稳定后再评估方案 B（管理页 schema 大改 exposure/toolExposure）。
4. **codemode 不启用**：与现设计冲突。注意 pi 0.99+ 会因 MCP/deferred 自动激活 codemode/tool_search——升级后需设 `autoEnableCodemode: false`（mcp.json 内）+ 不加 `+codemode`，并核 defaultTools。
5. **沙盒插件并入 amedac-core**：源码从独立仓库（pi-sandbox-extension，LabTrainingProject 与 AgentSandbox 两份同 HEAD 检出 e33f4ec）迁入 `pi-config/agent/extensions/amedac-core/`，以 sandbox-platform.json 存在性为激活门槛（沙盒 home 才加载），打包脚本与 PI_WEB_SANDBOX_EXTENSION_PATH 接线同步改造。
6. **lab-training**：pi-lab-training-cli peerDeps 为开区间 >=0.80.0，跟随宿主 pi；pi 1.x 接口变更点（shouldStopAfterTurn 移除等）升级后回归其测试。
