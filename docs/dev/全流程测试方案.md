# 全流程测试方案

> 状态：现行（2026-11-23）。目标：每次改动都有「本地可跑、VM 可验、发布前可回归」
> 的标准路径，并可供 QA 子智能体无人值守执行。功能点清单见
> [平台功能检查手册.md](./平台功能检查手册.md)。

## 1. 层级

| 层 | 环境 | 覆盖 | 命令 |
|---|---|---|---|
| L0 静态/单元 | 本地 | tsc、单测、i18n、组件、Go 单测 | `npx tsc --noEmit && npm test` + `cd agent && go test ./...` |
| L1 本地全流程 | 本地 dev + mock 平台 | 登录、项目、配置、信任、MCP、文件/终端、向导 | §2 |
| L2 VM 实机 | 10.99.9.7 | 沙盒容器、SSH、relay、下载/升级、打包 | `node scripts/vm/vm.cjs deploy --branch <branch>` |
| L3 浏览器 E2E | 本地/VM | 真实浏览器 host/auth/live 三世界 | `e2e_playwright` 仓库 |

判级：

- 纯 UI/纯前端/平台无关 API：L0+L1；
- remotefs/ssh/relay/sandbox/MCP host/打包：追加 L2 对应用例；
- 登录/权限/会话/项目删除/投影：追加 L2 多用户隔离与 L3 相关世界。

## 2. L1 本地



## 3. L2 VM

部署：

```bash
cd pi-web-0851
node scripts/vm/vm.cjs deploy --branch dev-0.85.1
```

前置：

- 代码已 push；VM 磁盘 ≥2G；
- 平台副本/数据目录存在；
- 需要本机模式：Agent 0.8.0（或至少 0.3.0，新功能 0.8.0）；
- 需要沙盒：Apptainer + 镜像。

| 编号 | 用例 | 关键点 |
|---|---|---|
| L2-01 | 构建/健康 | BUILD-OK、30141 LISTEN、webauth-config 200、wrapper log 无 fatal |
| L2-02 | 下载/升级 | agent 下载 200、size/version 正确；旧 `pi-agent-*` 别名 |
| L2-03 | 沙盒全链路 | 建项目 → 容器 → bash `pwd=/workspace` → 文件/PTY |
| L2-04 | SSH 全链路 | 测试连接 → 目录浏览 → 工具/终端/`!` |
| L2-05 | 本机 relay | 配对 → 多机器选择 → 工具/文件/终端 |
| L2-06 | 本机 MCP host | plane=workspace + lazy/directTools=false → 新会话出现 `mcp_*` → 调用 → 关闭 |
| L2-07 | 多用户隔离 | admin/test 项目、会话、Host、bundles、relay、MCP |
| L2-08 | 批量 API | host/sandbox/local-machine 三模式、SSE、取消、限流 |
| L2-09 | AppImage/tar 升级 | 数据保留、迁移、回滚 |
| L2-10 | OTLP | MLflow trace/Response/多轮 session.id |

## 4. L3 浏览器 E2E

独立仓库 `e2e_playwright`：

- `host`：Host 项目/会话/文件/终端；
- `auth`：登录、角色、隔离；
- `live`：真实平台/容器/多用户；
- 每个世界启动前清 `.next/dev`，避免 Turbopack 跨世界 panic；
- 真实容器世界需要平台 + Apptainer（当前实测 10.99.9.7）。

命令与用例定义见 `e2e_playwright/docs/E2E-DESIGN.md`。

## 5. 回归集

- **冒烟**：L0 + L1-01/03/09/10/11/12。
- **标准**：L0 + L1 全部 + 改动相关 L2。
- **发布**：L0 + L1 + L2 + L3 相关世界；打包/升级全量。

## 6. 安全回归（S）

| 编号 | 用例 | 期望 |
|---|---|---|
| S-01 | 伪造 cookie 访问 sessions/files/terminal | 401/403，不返回数据 |
| S-02 | 跨用户 session id | 404/403（remotefs/terminal/events 全拒） |
| S-03 | relay token 原型链 | 连接拒绝 |
| S-04 | 配对/登录限速 | 429/限流 |
| S-05 | 平台 fail-closed | 无 executor/JWT 配置时拒绝启动或明确告警 |
| S-06 | MCP 不安全字段 | 创建/导入/同步/会话启动拒绝 |
| S-07 | Host 目录/配置包路径穿越 | 403/400，无写入 |
| S-08 | 管理员禁用用户 | 本地登录态失效、live wrapper 停止 |

## 7. 多机（M）

| 编号 | 用例 | 期望 |
|---|---|---|
| M-01 | 同用户双机配对 | machines 均在线，项目绑定各自机器 |
| M-02 | 项目按 machineId 路由 | P1/P2 工具命中不同 root |
| M-03 | 单机兼容 | 未绑定项目使用默认机器 |
| M-04 | 离线机器 | 报明确离线错误，不影响另一项目 |
| M-05 | 同 machineId 重连 | 409/--replace，旧 pending 拒绝 |
| M-06 | 解绑 | token 失效，WS 断开 |
| M-07 | 终端隔离 | P1/P2 输出不串 |
| M-08 | MCP host 隔离 | 两项目 serverKey/进程互不干扰 |

## 8. QA 子智能体

- 定义：`pi-config/agent/agents/qa-e2e-tester.md`。
- 建议视觉模型；只执行测试与报告，不修复。
- 输入：层级/回归集、环境、证据目录、报告路径。
- 报告结构：环境（git rev/端口/角色）→ 总表（编号/结果/证据）→ 失败详情（P0-P3、
  复现、期望/实际、疑似层级）→ 建议回归范围。

## 9. 证据与发布门禁

- 每个用例留 curl 输出/截图/日志摘录；
- P0 主流程不可用/数据丢失/越权必须修复后重跑；
- 发布前至少：L0 全绿、L1 标准集、L2 构建/健康、相关 L2 功能；
- 文档随代码变更同步更新（PLATFORM + 对应专题）。
