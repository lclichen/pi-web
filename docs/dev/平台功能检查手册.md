## 0. 环境与权限

| 项 | 要求 |
|---|---|
| WebUI | `:30141` |
| Relay | `:30142`（本机模式） |
| Platform | `:3000`（沙盒模式，可被反代隐藏） |
| 浏览器 | admin / test 两个隔离窗口 |
| 可选 | Apptainer、配对 Agent、SSH 主机、至少一台第二机器 |

权限基线：

| 能力 | 普通用户 | 管理员 |
|---|---|---|
| 沙盒/本机/SSH/Quick 会话 | ✅（本机需配对） | ✅ |
| WebUI Host 项目/会话 | ❌ | ✅ |
| Host(CLI) 空间 | ❌ | ✅ |
| 他人会话/文件 | ❌ 404 | ✅ 支持视图 |
| 全局配置/模型/MCP/模板 | ❌ | ✅ |
| 用户配置 | ✅ 自己 | ✅ |
| 删除用户/平台资源 | ❌ | ✅ |

## 1. 登录与多用户

1. 未登录访问 `/` → `/login`；admin/test 分别登录成功。
2. 未登录 `/api/sessions` → 401。
3. 两个窗口互不可见项目/会话；管理员 Host(CLI) 例外。
4. 登出后回登录页；禁用/改角色/重置密码后旧会话立即失效。

## 2. 新建项目向导

入口：侧栏「新建项目」。

### 2.1 沙盒（需平台 + Apptainer）

1. 填项目名/镜像（或复用容器/云盘初始化）。
2. 创建供给容器；④ 目录固定 `/workspace`。
3. 会话 bash `pwd` = `/workspace`；文件面板/终端都进容器。
4. 平台/容器不可用时明确报错，不回落到服务器本地。

### 2.2 本机

1. 填项目名 → ③ 选择/配对机器 → ④ 选本机工作目录。
2. 会话工具、文件面板、终端都落到该机器；服务器不留工作区副本。
3. 机器离线/版本过低时明确报错；项目绑定 `machineId`，不静默换机。

### 2.3 SSH

1. 填主机/端口/用户/密码或私钥；测试连接返回 whoami。
2. ③ 自动测试 → ④ 浏览远程目录 → 完成。
3. 会话 bash `pwd` = 远程目录；文件面板 SFTP；终端 ssh2 PTY；`!` 命令转发远端。
4. 凭据 0600，不进配置包。

### 2.4 服务器目录项目（admin）

1. 普通用户看不到该卡片。
2. 选择服务器已有目录 + 填项目名；必须点“完成”创建，不会选目录即入项目。
3. 删除项目只删记录，目录保留。
4. 创建后自动置顶并进入新会话。

## 3. 会话基础

1. 新建会话、流式回复、重命名、删除、置顶。
2. 运行中队列（steer/followUp）、clear_queue。
3. fork/clone、navigate_tree、compact。
4. 运行中不可切换工具模式/执行模式；恢复后模式不变。
5. 会话归属/space 切换对普通用户正确隐藏。

## 4. Host 与 Quick

### Host(CLI)（admin）

1. 侧栏“我的会话 / Host(CLI)”切换。
2. 服务器 CLI 创建会话 → 按目录分组出现。
3. 普通用户 `?space=host` 返回空。

### Quick

1. 模板选择、无工作区问答。
2. 每 `(user,template)` 一个 Quick 项目；模板更新生成新 workspace 版本，旧会话保留。
3. 模板删除标记 missing，不清会话。
4. Quick 不参与项目配置包。

## 5. 配置包 / 模板 / 同步

1. 项目导出 → 解包含 `.pi/`/AGENTS.md；不含 auth/ssh/sandbox 凭据。
2. 导入 → 文件清单、覆盖语义、失败不半写。
3. 含 `../`/超限/非法 schema → 拒绝且原配置不变。
4. 普通用户导入控制面 stdio → 拒绝；local-machine + plane=workspace 且 safe → 允许。
5. 管理员设置→配置模板：上传/列表/删除；创建项目可选模板。
6. 项目套用模板；Host 目录套用要求无 `.pi`（409）。
7. 工作区 → 项目同步：dry-run diff → 应用 → 备份/回滚；stdin/凭证/MCP 闸门生效。

## 6. Skills / Agents / MCP / Plugins

1. 设置按项目/用户/全局分组；权限正确。
2. 技能上传 zip：裸 SKILL.md/多目录；无 SKILL.md 拒绝；新会话生效。
3. Agents：内置只读 + 项目/用户/全局文件代理可编辑；子代理工具 schema 隔离。
4. MCP：
   - HTTP MCP 可添加；测试连接。
   - 普通用户 project/user stdio 默认拒绝。
   - local-machine 项目：plane=workspace + lifecycle=lazy + directTools=false 可创建；
     新会话列出 `mcp_<server>_<tool>`；调用走 Agent；工具结果文本/图片正常。
   - 不安全字段（keep-alive/eager/directTools≠false）→ 创建/导入/同步/会话启动拒绝。
   - Project 墓碑关闭全局服务器；重新启用行为正确。
5. Plugins：安装/启停/作用域；离线模式禁用按钮/409。
6. 项目信任：未信任项目弹出提示；信任后 Skills/Agents/MCP/Plugins 原地刷新。

## 7. 文件与终端

1. 文件面板：列目录、新建、重命名、删除、上传、下载、预览（文本/图片/PDF/DOCX）。
2. 大文件/长 Markdown 不能卡死；文件引用 `@` 菜单可用。
3. 终端：Host 本地 PTY；沙盒平台 PTY；本机 relay PTY；SSH PTY。
4. Windows Agent 终端为桩，应明确不可用而不是假连接。
5. 远程终端镜像环境是创建时快照；重开终端生效。

## 8. 沙盒容器管理（admin）

1. 容器列表/启停/删除/快照/绑定项目。
2. 快照保存/恢复/导出；配额/镜像白名单错误透传。
3. 平台管理面板/审计日志/健康指标。

## 9. 批量任务 / 嵌入 / 分享 / 追踪

1. 批量 API：host（admin）、sandbox、local-machine；SSE、取消、结果、并发限流。
2. 嵌入页：API key 换短期 token；固定项目围栏；重命名/归档/删除。
3. 分享：Host 活引用/远程快照；TTL/下载次数；无 Cookie 可访问；session 删除后失效。
4. OTLP：配置 endpoint/headers；一次会话产生 GenAI span，MLflow Response/多轮分组正确。

## 10. 设置与账户

1. 通用（主题/语言/聊天宽度/字号）、模型、技能、Agents、MCP、插件、API 密钥、全局配置。
2. 普通用户看不到管理员 tab；`/api/webauth/me` 角色正确。
3. 修改密码、登出、登录态窗口、禁用用户后重登。
4. 设置页滚动/分区/紧凑模式在 1200px 与窄屏正常。

## 11. 观测与性能

1. 页面静置不应每秒轮询 `/api/sessions`；只有 `/api/agent/running` 轻量轮询。
2. relay status SSE 30s 心跳；无重复事件流。
3. 服务日志无未捕获异常刷屏；文件日志有轮转。
4. 批量/大文件/长会话不触发内存守卫误杀。

## 12. 打包与升级

1. `package-linux.sh` 产物 + SHA256；CLI/WebUI/平台 mock 冒烟。
2. `slim-package.sh` 自检通过（Next wasm/SWC/pi-coding-agent；无真实 sharp 残留）。
3. AppImage `--web/status/stop`，数据在 `AMEDAC_HOME`。
4. 升级保留 config/data；旧布局迁移；回滚。
5. 下载路由返回正确 Agent 版本/大小；用户机器安装后 version 正确。

## 13. 已知限制

- 单 Node 进程托管 Agent 会话；高并发需拆执行面。
- Windows Agent PTY 不可用。
- sandbox/SSH 的 workspace stdio MCP 未支持。
- MCP 内部路径不受 path-guard；只信任来源明确的 MCP。
- 部分 state store 未统一锁/GC；平台账号外部删除依赖管理端/401 复查。
